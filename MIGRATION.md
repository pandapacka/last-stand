# Миграция убежища — этап 1
Node.js 24. Из корня выполните npm ci, затем npm run dev. Для сборки и проверки выполните npm test, npm run build и npm run preview. Публикация Pages для этого этапа не требуется.

## Границы модулей
- client/Shelter.ts — сцена Phaser 4.2.1, отдельные PNG, изометрия, выбор по альфа-каналу и порядок отрисовки. Основа земли подготовлена зеркальным повторением внутреннего участка grass.png. Сетка и граница хозяйственной зоны запечены в PNG размером в две логические плотности.
- client/legacy.js — действующие HTML-экраны, касания, каталог, таймеры и старые системы. При старте читается laststand_phaser_v1, затем v08/v05/v01 с прежней нормализацией данных. Запись ведётся под новым ключом. localStorage привязан к origin, поэтому отдельный localhost не имеет доступа к сохранению GitHub Pages.
- shared — координаты, размеры клеток, коллизии и правила размещения. server/construction.ts принимает команду только после проверки зоны, свободной клетки и ресурсов, выставляет срок по часам обработчика. Сейчас вызывается локально. Сетевой транспорт Colyseus, идентификация игрока и транзакции PostgreSQL — следующий этап.
- Сроки производства, кухня, ферма, экспедиции, заражение, сюжет и оборона пока исполняются прежним кодом.

## Источники GZ Heroes of Worlds
Локальная версия f091bfe. Из src/city/cityIso.ts взяты прямое/обратное преобразование и isoSortKey. Из src/editor/editorGrid.ts — snapToPlacement и размер единицы. В убежище четыре малые единицы соответствуют одной клетке строительства. Из src/editor/placementResolve.ts перенесена проверка пересечения прямоугольников. Наложение блокирует команду. Предпросмотр адаптирует повторно используемый полупрозрачный Phaser Image с нижней точкой опоры из EditorScene.updateGhost. Каталог, двухпозиционный поворот и мобильные жесты происходят из Last Stand. Маркер рейда — отдельный PNG зомби. Старый редактор и его модель контента не подключены.

## Этап 2 — производство
Каталог рецептов и проверка ингредиентов находятся в shared/recipes.ts и shared/kitchen.ts. Порядок рецептов сохранён для совместимости очередей. server/production.ts принимает заказ, выдаёт готовые порции и обрабатывает индивидуальные сроки строительства и выработки мастерских. Обычная и автоматическая готовка вызывают один обработчик. Ферма, экспедиции, питание и заражение пока используют прежнюю реализацию.

## Этап 3 — ферма и поселенцы
server/farm.ts хранит остаток роста, момент расчёта и срок влаги. Новая грядка сухая. Полив даёт 20 минут влаги. Одна порция удобрения удваивает скорость до сбора только во влажной почве. Старые сроки пересчитываются при загрузке. Для проверки выдаётся 100 порций на сохранение. server/settlers.ts обслуживает питание и заражение на прежних персональных сроках.
